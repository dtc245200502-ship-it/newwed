# jsp-servlet-demo

Ứng dụng Java Web đơn giản sử dụng Maven, JSP và Servlet.

## Công nghệ

- Java 17
- Maven
- Jakarta Servlet 6.0
- Jakarta JSP 3.1
- Apache Tomcat 10.1+
